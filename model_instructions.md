## Agent Tips
- Do not make assumptions, ask everytime when there are uncertanties
- Break down the problem into small steps and take on at a time
- Keep everything consistent
- Add comments to the code that is not clear enough
- Create documentation for each service
- Create README file with how to start the project

## Coding standards
- Clear, consistent names for variables, functions, and classes
- Organizing code into small, modular functions and classes to improve maintainability
- Minimizing code duplication through reusability
- Adhering to object-oriented design principles to enhance code adaptability

## Package standards
- Always check for conflicts between version
- Use the latest version when it is possible, but do not overwrite conflicts rule
